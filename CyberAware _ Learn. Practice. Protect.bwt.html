Password Security

Create strong, unique passwords and protect your accounts.

◷ 5 min read
Use a long passphrase or a password manager to create unique passwords for every account. Turn on multi-factor authentication (MFA). Never share one-time passwords or recovery codes. If a service reports a breach, change the affected password and any reused passwords.
